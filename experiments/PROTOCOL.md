# A/B 测试协议 v1.1（草案，已过一轮独立审查，待用户批准）

用途：每个项目、每个品类都用这一套。ab-01 是试点（pilot），不是基线：各组契约版本不一致、A 只有 1 个样本、剔除测试用了事后规则。试点结论不能据此认定模板有效或无效。

本协议第一层只写**角色约束**，不写具体模型名、文件名或技术栈；这些在每轮的评测包里写明，随 tag 冻结。数字以 harness 的 `journal.jsonl` / `STATUS.md` 为准。

## 第一层：协议（跨项目不变）

### 1. 组与样本
- **对照 C**：简报 + 契约。**B+T**：契约 + 可运行验收。**A**：完整规格 + 阶段 + 验收。**A−阶段**（可选）。
- 每组 **n ≥ 3**，同一轮用同一版蓝图 tag 和同一版 harness tag。各组**交错执行**（不按组连续跑），避免 provider 负载随时间漂移。
- 每组事先固定最大轮数和墙钟上限。超时或没到 DONE 记为**未达到**，计入样本，不许换一次重跑。
- 主比较只比质量。用时另做小样本串行对照，不并入判定。

### 2. 角色与模型（角色约束；具体模型写在评测包）
- 构建者、审查员、缺陷核实员、测试裁决员、留出测试作者、模拟用户：**核实员与裁决员的模型家族必须与构建者不同**；两位作者家族互不相同，且都不与裁决员同家族。审查员与构建者同家族是已知局限（盲区相关），在每轮报告里注明。
- 免费模型只用于写留出测试和辅助活，不当构建者。

### 3. 冻结点（git tag，之后不改）
1. 评测包冻结（构建前）。2. 构建完成。3. 打分完成。
冻结后唯一允许的改动：第 4 条的盲审剔除，且必须同时报告剔除前和剔除后两套分数。

### 4. 测试有效性
- 一条测试只能断言它所引用的条款**明确写出**的内容。
- **准入**：每条留出测试在**空应用上失败**、在**参考实现上通过**（参考实现不得是被打分的产品）。
- 构建前，独立裁决员逐条对照条款检查，剔除不成立的。
- 构建后，只有同一裁决员能推翻某条测试，且只看「测试 + 条款 + 匿名失败响应和日志」，**不看代码，也不看有几个产品失败**。每次剔除都留记录。
- 不得用被打分产品的结果决定剔除哪条测试。

### 5. 指标与判定规则（先于数据写下）
**入围前提（不过 = 该次记为「未达到」）**：品类不变量探针全过；通过自带验收。
**主指标**（对每次构建）：
1. 留出测试失败数——**只用 contract 桶判定**。
2. 经核实的高危/中危缺陷数。统一做法：所有组只对**最终快照**用同一提示审一次，代码匿名，再由不同家族的核实员复现；阶段内的审查不计数。比较用每组的**中位数**。
**描述性指标**（报告，不入判定）：spec 桶失败数（只含能从用户简报推出的条目）、模拟用户阻塞问题、用时、花费、人工介入次数。

**判定**：比较的是事先指定的组对（如 B+T 对 C、A 对 B+T）。形态 X 优于 Y，须同时满足：contract 桶失败数中位数低**至少 3 条**，且两组范围不重叠（或 9 次两两比较中 X 胜出 ≥7 次）；并且经核实缺陷中位数不更高。两个指标冲突，或差距不够，判「不确定」，可补到 n=5，补跑规则事先固定，不许看数据后再定。打平选更简单、更便宜的形态。

### 6. 卫生（由 harness 强制）
- 运行 id 不得复用；记录并发数；每个实验启动前写好预测文件，事后只填「实际」。
- 留出测试与可见验收做去重标注；打分时报告去重前和去重后两套。
- 免费作者写出过错误测试（`toBeVisible`、辅助函数自己断言状态码）——准入规则（第 4 条）为此而设。

## 第二层：每个项目一份评测包（目录形状固定）
`experiments/<项目>/pack/`：
- 简报、契约、验收；技术栈、模型版本、文件名写在 `pack/CONFIG.md`。
- `holdout/contract/`、`holdout/spec/`：两位不同家族的作者写；构建前经裁决员审过、通过准入、打 tag。
- `invariants/`：品类不变量探针（核心价值路径真的执行）。**探针在构建前用参考实现验证能过，再用人为植入缺陷的版本（空壳、整篇塞进提示词等）验证会失败**，不得用被打分的产品当正对照。
- `usersim/`：模拟用户脚本（见下方「待用户决定」），逐步记录是否完成、是否阻塞、报错文字、困惑点；「阻塞」由不同家族的评判者盲判。
- 质量线（contract 桶失败数上限 + 探针全过 + 0 条已核实高危缺陷）在**第一个项目冻结时**写死；第二个项目单独建评测包，引用这条质量线，经济门表 `economics.md` 在第二个项目里填（总用时含模板适配 + 人工时间）。
