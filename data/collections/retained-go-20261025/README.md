# 原始采集产物留档

这些是60批采集尝试的原始输入、草稿、研究记录、初审与状态快照，**不代表正式入库或最终通过**。原记录中的case_found也是采集者当时的判断，当前正式状态以`../included-coverage-progress.json`及最终复核报告为准。

各part文件保持原内容。`sources/<sha256>.txt`引用的正文统一在上级`data/collections/sources/`，不是各part文件夹下；原始模型日志与未完成过程笔记仍在`var/collection/opencode-go/`。只通过显式导入最终筛选批次发布，不能批量导入这里的原始batch.json。

证据不足、初审未过和产物缺失分别记录；不据失败断言产品或类型不存在，不归档目录类型。
