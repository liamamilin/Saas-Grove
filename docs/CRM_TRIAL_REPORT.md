# CRM 个人试用闭环（2026-11-04）

试点候选复用正式库的 Twenty（github:572984571）与 EspoCRM（github:24459441）。正式 1,520 产品／1,816 关系、分类、资源与原始研究资料不变；只在本地使用。

## 走查与交付

实施前实际用隔离浏览器完成两候选比较并保存。走查发现：原流程能保留个人结论，但没有试用入口、逐项结果、版本条件或最终选择的修订历史。

- 从已保存的 CRM 比较生成个人试用计划，入口在比较页和候选清单。默认六项：客户与线索、商机、导入导出、API、部署维护、版本与扩展边界。可选择模板、调整要求、设置必需/可选、停用项目或新增自定义检查。
- 每项记录待验证、通过、未通过或不适用；区分“只核对资料”和“本人实际操作”。完成结果须填版本、条件、日期及至少一种依据（说明、链接或截图），不适用需说明原因。
- 官方事实、引文和来源单独展示，缺项保持未核实。每次保存追加个人历史；修改验收要求后，原结果保留，当前要求重新待验证。所有本地写入使用同一 Web Locks 锁并在锁内重读，两个标签同时保存也能保留追加历史；收藏按点击时意图幂等写入。
- 最终选择可选候选或暂不选择，记录理由、疑问与其他候选的暂不选择原因；每次保存保留选择历史。有未完成必需项时明确提示，不强行阻止保留有条件的个人选择，不计算产品分数。
- 验证截图为本地 PNG/JPEG/WebP，单张不超过 500KB。全部记录与截图随完整备份导出；官方目录的 `runtime_tested` 不受个人记录影响。
- 试用计划固定创建时的候选 ID 并仅缓存候选显示名（不缓存官方能力），API 不可用时仍能识别历史归属；旧计划缺少名称时保留历史，等待资料恢复后再保存新选择。不会随原比较的后续修改变化；删除比较或取消收藏不会自动删除试用历史。产品详情与当前官方比较可返回试用上下文。`/trials/:id` 支持直接访问和刷新。

## 原有记录兼容

继续使用 `saas-grove.saved-products.v1` 键。读取 v1/v2 不写回，首次用户保存后写 v3，保留收藏 ID/时间、备注、比较与个人结论。v3 阻止旧 v1/v2 页面在不理解新字段时覆写整份记录。实际用户浏览器存储未被自动迁移或读取。

新完整备份为 `saas-grove.local-backup` v2，包含 trials；接受旧备份 v1。导入先预览，当前同 ID 记录优先，包括试用计划的整个当前版本；没有出现在备份里的记录不删除。无效引用、危险证据地址或格式不明的截图拒绝写入，容量不足也保留原数据，验证、清单要求、选择和删除失败均在操作区域提示；删除整个计划前要求确认。截图容量依赖浏览器 localStorage，建议裁剪并定期导出。

## 范围与限制

- 试用生成入口先在 CRM 开放，支持从现有比较的 2–4 个候选创建，首个试点使用两个候选。
- 现代本地浏览器通过 Web Locks 串行化跨标签写入；不支持此 API 的旧环境仍可单标签保存，但不承诺同时多标签写入安全。
- 个人数据只在当前浏览器/访问地址；计划链接在其他浏览器不能独立读取，需导入备份。
- 同 ID 计划的备份导入保留当前整个版本，不混合不同备份里的修订历史；导入预览有明确说明。
- 上传的截图可能迅速占满本地存储，失败时保留旧记录；没有云文件存储或跨设备同步。
- 旧产品、资料和目录范围均未扩充；没有部署第三方 CRM，没有自动把个人选择升级为官方结论。
