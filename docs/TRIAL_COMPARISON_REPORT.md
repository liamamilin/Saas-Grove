# 个人试用结果并排总览（2026-11-04）

本轮在原比较页接入已有个人验证记录。用户明确将真实 CRM 试用调整为仅做形式验证，因此没有安装容器环境、部署或操作 Twenty/EspoCRM；所有验收个人记录均标为界面样例，不作为第三方产品能力结论。

## 可用流程

- 候选清单的试用计划新增“并排查看验证”；试用工作区可进入“查看官方与个人比较”。普通比较页也可选择对应计划。
- 同一类型、完整相同候选集合才匹配。换序按产品 ID 对齐；多计划须选择一份，不合并结果；链接里的计划缺失或候选被更换时明确提示，并提供按原候选恢复的入口。
- 官方资料与个人总览分区。每行是同一验收要求，各列展示当前结果、资料核对/本人操作方式、版本、环境、日期、说明和依据。缺失保持待验证，要求变更后旧结果仅供历史参考。
- 支持只看必需项、待解决/未通过/不适用、状态或方式不同。后者仅比较已记录状态和验证方式，不推断产品差异或优劣；版本与条件单独呈现，不自动评分。
- URL 保存 `trial`、`trial_required` 和 `trial_filter`，保留原官方比较条件。逐项入口定位正确候选与检查项并展开，返回继续原比较与筛选；官方资料异步加载后重新定位总览。
- 手机在表格容器内横向查看，要求列不固定遮挡候选，并在候选单元格重复检查项名称。页面无横向溢出。
- 总览只读，沿用个人 v3 与备份 v2，不新增数据库字段或格式迁移；原收藏、备注、比较、验证与选择历史均保留。写入失败与实际读取失败分开处理，保存失败不会隐藏仍可读取的观察记录。
