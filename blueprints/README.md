# blueprints/

这里放模板。每个模板都是一份交给 coding agent 的"说明书 + 契约 + 可执行验收"，让它把一类产品做到成熟。格式见根目录 `README.md` 的"模板格式 v0"。

| 模板 | 品类 | 状态 |
|---|---|---|
| [`ai-research-assistant/`](ai-research-assistant/TEMPLATE.md) | AI 原生应用 | 草稿 v0.1.0：spec 和验收已写好，等待人工审批，还没有经过 agent 实做验证 |

**一个模板只有在 agent 照着它做出了产品、并通过它自带的验收之后，才算合格。**
